## 3. Git Collaboration Workflow for Phase 1

```
main (verified Phase 1 release for Oct 30 submission)
  ▲
  └── integration (integration staging branch, managed by M1)
        ▲
        ├── feature/m1-token-driver (M1)
        ├── feature/m2-lexer-core (M2)
        ├── feature/m3-symbol-table (M3)
        ├── feature/m4-ident-num-scanner (M4)
        └── feature/m5-str-op-scanner (M5)
```

1. **Feature Branches:** Each member works on their isolated feature branch.
2. **Pull Request Protocol:**
   - Members open PRs to `integration`.
   - Member 1 runs `python3 -m unittest tests.test_contract` and the full test suite before merging.
   - For Member 1's PRs, Member 4 reviews and merges.
3. **Clean Tagging:** Once Checkpoint 6 passes, tag the commit as `phase-1-final`.
